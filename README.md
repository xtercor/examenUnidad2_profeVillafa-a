# Examen 01 - Plataformas 2D

Proyecto realizado en Unity como práctica de desarrollo de videojuegos 2D.

## Controles

- A / D o flechas: mover al jugador.
- W, flecha arriba o espacio: saltar.

## Características

- Movimiento y salto del jugador.
- Plataformas con colisiones.
- Zona de rebote.
- Zona de daño y reaparición.

## Requisitos

- Unity 6000.6.4f1.

## Ejecución

Abrir el proyecto desde Unity Hub y ejecutar la escena `MainScene`, ubicada en `Assets/Scenes/`.
